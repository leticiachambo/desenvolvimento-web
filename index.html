Sobre o projeto

Este site foi desenvolvido como atividade da disciplina Desenvolvimento Web. O objetivo é praticar HTML semântico, layout responsivo com Bootstrap 5 e requisições AJAX com a Fetch API.

Autora: Letícia Souza dos Santos Chambó

Perguntas frequentes

A listagem é obtida com fetch("data/itens.json"). Ao clicar em Ver detalhes, é feita uma nova requisição para data/detalhes/{id}.json e o resultado é mostrado em um modal.

  • HTML5 semântico
  • CSS próprio + Bootstrap 5.3 e Bootstrap Icons
  • JavaScript puro (sem frameworks) com Fetch API
  • Arquivos JSON locais servidos por HTTP

Textos escritos para este projeto com base no site oficial e nos trailers de GTA VI divulgados pela Rockstar Games. As imagens são material oficial de divulgação da Rockstar Games, usadas apenas para fins educacionais.

Adicione ?lento=1 ao endereço para ver o indicador de carregamento por mais tempo, ?erro=lista ou ?erro=detalhes para simular uma falha na requisição e testar o botão Tentar novamente. Buscar um termo inexistente (ex.: xyz) mostra a mensagem de nenhum resultado.
